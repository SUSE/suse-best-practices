== Scope of this document

This document describes how to set up the cluster to control the data base instances and system replication 
for the scenario {HANA} {usecase}.

The document focuses on the steps to integrate
an already installed and working {HANA} with System Replication.
To create this document, {sles4sap} {prodNr}.{pMinor16} was used. However, the concept
can also be used with {sles4sap} {prodNr}.0 or newer.

The described example setup builds an {HANA} HA cluster in two data centers in
{saplocation1} ({sapsite1}) and in {saplocation2} ({sapsite2}), installed on two
{sles4sapa} {prodnr}.{pMinor16} systems.
