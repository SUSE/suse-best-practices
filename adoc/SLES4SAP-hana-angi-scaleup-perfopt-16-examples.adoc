=== Example cluster configuration
:sapnode1: besler3
:sapnode2: besler4
:sapsid: HA1
:sapino: 00
:sapip1srv1: 192.168.2.66
The following complete progressive crm configuration is for a two-node cluster
({sapnode1}, {sapnode2}) and an {HANA} database with SID {sapsid}
and instance number {sapino}. A failed primary will be automatically registered
as secondary after reboot.
Priority fencing prefers the {HANA} primary in case of split-brain.
The virtual IP address in the example is {sapip1srv1}.
